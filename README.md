## 📌 Project Overview

A menu-driven Banking System developed in C to perform basic bank account operations using functions, structures, and file handling.

## ✨ Key Features

- 💰 Deposit Money
- 💳 Withdraw Money
- 📊 Balance Enquiry
- 🔒 Insufficient Balance Validation
- 💾 Permanent Data Storage
- 🚪 Exit System

## 🛠️ Technologies Used

- C Programming
- Functions
- Structures
- File Handling
- Clang Compiler

## ⚙️ How to Run

### 1. Clone Repository

```bash
git clone YOUR_REPOSITORY_URL
cd CodeAlpha_BankingSystem
clang bank.c -o bank
./bank
```
